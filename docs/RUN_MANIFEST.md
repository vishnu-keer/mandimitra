## Reproducibility, measured

- The same environment produces **byte-identical** files on every run (checked by rebuilding from the official files twice).
- CPython 3.11 and 3.12 on Linux with the pinned requirements produce byte-identical files to each other.
- A different interpreter or platform (measured: CPython 3.10 on Linux) changes only the ARIMA numbers, by at most about 0.04 Rs./quintal in a prediction and 2e-3 in an RMSE, through floating-point differences in statsmodels' optimiser. The tree models, Naive, the selected models and every PASS/FAIL decision are unchanged. `scripts/check_reproducible.py` checks a rebuild against these files with exactly that tolerance.
